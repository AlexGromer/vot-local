VOT для AIMP
============

Плагин добавляет в контекстное меню плейлиста AIMP пункт «Перевести (VOT)».
Он переводит выбранные файлы (видео или аудио) программой vot-local и добавляет
в плейлист файл <имя>.ru.m4a: русскую озвучку поверх приглушённого оригинала.

Установка
1. Сначала установите VOT-local (install.cmd в папке C:\VOT-local).
2. Дважды щёлкните vot_local.aimppack — AIMP предложит установить плагин.
   Или: AIMP -> Меню -> Настройки -> Плагины, включите «VOT: закадровый перевод».
3. В плейлисте выберите файл -> правый клик -> «Перевести (VOT)».
   Откроется окно с ходом перевода; когда оно закроется, файл появится в конце плейлиста.

AIMP — аудиоплеер, поэтому результат — только звук (m4a).
