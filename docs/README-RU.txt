VOT-local: закадровый перевод видео с компьютера
================================================

Программа переводит видеофайл с компьютера тем же сервисом, что и расширение
«Закадровый перевод видео» (VOT), и сохраняет рядом новый файл с русской озвучкой.
Для просмотра лучше всего подходят VLC или PotPlayer: в них легко переключать
звуковые дорожки. Встроенные плееры Windows могут не показать выбор дорожки.

Установка (один раз)
--------------------
1. Правый клик по скачанному архиву -> «Свойства». Если внизу есть галочка
   «Разблокировать», поставьте её и нажмите «ОК».
2. Правый клик по архиву -> «Извлечь всё…» -> укажите C:\ -> «Извлечь».
   Получится папка C:\VOT-local. Не запускайте файлы прямо из окна архива.
   Не перемещайте и не удаляйте папку после установки (если переместили,
   запустите install.cmd ещё раз).
3. Откройте папку C:\VOT-local и запустите install.cmd.
   Должно появиться сообщение: Пункт «Перевести (VOT)» добавлен в меню видеофайлов.
   Права администратора не нужны.
   Если появится синее окно «Система Windows защитила ваш компьютер», нажмите
   «Подробнее», затем «Выполнить в любом случае».

Как перевести видео
-------------------
1. Правый клик по видеофайлу -> «Перевести (VOT)».
   В Windows 11 пункт находится в «Показать дополнительные параметры».
   Переводите по одному файлу. Подходят .mp4 .mkv .avi .mov .webm .m4v .wmv
   .flv .mpg .mpeg .3gp .m2ts .mts.
2. Откроется окно с ходом работы. Нужен интернет. Время перевода задаёт сервис:
   короткое видео обычно занимает минуты, фильм дольше. Не закрывайте окно,
   пока не появится «Готово».
3. Рядом с видео появится файл с окончанием .ru.mkv, например «лекция.ru.mkv».
   Первая звуковая дорожка — перевод поверх приглушённого оригинала (включена
   сама), вторая — оригинал без перевода.
4. Нажмите Enter, чтобы закрыть окно.

Что важно знать
---------------
- Пока идёт перевод, звук из видео (без картинки) временно доступен по
  случайной ссылке. Его скачивает и обрабатывает сервис перевода Яндекса, а
  передаётся он через сервис Cloudflare. Ссылка перестаёт работать, как только
  перевод готов или окно закрыто. Не переводите записи, которыми нельзя
  делиться с этими сервисами.
- Антивирус может по ошибке заблокировать vot-local.exe или cloudflared.exe:
  программа не подписана, а cloudflared создаёт туннель. Если файл пропал,
  восстановите его из карантина и добавьте папку C:\VOT-local в исключения.

Если не получилось
------------------
Окно покажет строку «Ошибка: …». Частые причины:
- нет интернета, или мешают VPN, прокси, антивирус -> проверьте и повторите;
- «Нет прав на запись в папку» -> скопируйте видео, например, на Рабочий стол;
- «Сервис перевода не смог перевести» -> в видео нет речи, или сервис
  временно недоступен; попробуйте позже.
Если не помогло, пришлите текст ошибки.

Удаление: запустите uninstall.cmd, потом удалите папку C:\VOT-local.
